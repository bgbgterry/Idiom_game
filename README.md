## 🎮 專案特色

1. **完整歷屆核心成語庫（570 則去重成語）**
   - 嚴格解析《116年版阿任師國文重點速記小卡（四）102～115年歷屆會考成語24p（含各年補考及大陸考場考試）》，完整收錄 **570 則不重複成語**、釋義、注音提示、歷屆出現年份標籤與高頻星號（`*` / `**`）。
2. **20 關卡 × 100 題 = 2,000 道四選一單選題庫**
   - 納入《應用文會考【成語】試題題庫》50 道種子真題，並延伸設計五大會考核心題型：
     - **題型 A【情境填空】**
     - **題型 B【釋義與典故】**
     - **題型 C【用法正誤判斷】**
     - **題型 D【字形與字音辨析】**
     - **題型 E【詞義關係（近反義與類比）】**
   - 每次進入關卡隨機抽取 **20 題**（滿分 100 分），選項順序動態隨機洗牌。
3. **挑戰者系統（`document.cookie` + `localStorage` 雙重同步）**
   - 內建 `StorageManager`，將所有挑戰者名單、當前活躍挑戰者、20 關最高分與錯題摘要寫入 `document.cookie`（365 天效期、`path=/`、`SameSite=Lax`，並具備 4KB 容量防呆壓縮保護），同時雙重備份完整錯題明細於 `localStorage`，支援多帳號一鍵切換。
4. **專屬錯題筆記本 & 消滅錯題重練模式**
   - 答錯題目自動記錄原題、玩家誤選答案 vs 正確答案、阿任師小卡釋義。
   - 支援依關卡、成語、歷屆年份、熟練狀態篩選，可撰寫個人記憶口訣，並啟動「⚔️ 錯題重練（消滅錯題）」模式。
5. **Gen-Z 新野獸派（Neo-Brutalism）× 多巴胺電玩 UI**
   - 支援「🌙 街頭暗黑霓虹模式」與「☀️ 多巴胺潮流亮色模式」切換、段位稱號升級系統（`Lv.1 國文脆友` ➔ `Lv.20 5A++會考戰神`）、Web Audio API 街機合成音效與過關 Confetti 撒花特效。

## ✅ 強制檢查點驗證（Checkpoint Validation）

執行以下指令即可重新建置題庫並執行自動化檢查點驗證：

```bash
python scripts/build_question_bank.py
python scripts/verify_checkpoint.py
```

驗證項目：
- `[PASS] 總關卡數 == 20`
- `[PASS] 每一關的題目總數 == 100（全遊戲總計 2,000 題）`
- `[PASS] 每關所有成語皆至少有 2 題作為核心測驗目標（targetIdiom，實測每成語 3～6 題）`
- `[PASS] 全數 2,000 題結構完整且無任何佔位符（Placeholder）`
